Saints Baseball - Winter Ramp (installable web app)

1. Open config.js in any text editor and paste your Apps Script web app URL between the quotes. Save.
2. Upload this whole folder to a free static host (Netlify Drop: app.netlify.com/drop, or Cloudflare Pages).
3. Open the address it gives you on a phone:
   iPhone: Safari > Share > Add to Home Screen
   Android: Chrome menu > Install app
   Mac/PC: Chrome or Edge install icon in the address bar (Safari on Mac: File > Add to Dock)
